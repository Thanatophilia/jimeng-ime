# 霁梦输入法

一个 Android 拼音输入法。librime 引擎，雾凇拼音词库，键盘层移植自 fcitx5-android。

**它不联网。** 除了你自己开的翻译功能，打字、联想、语音识别全在手机上完成。

## 输入

雾凇拼音驱动，简繁都支持，中英可以混着打。

左边一列拼音音节，点哪一格就锁哪一格改谐音，改完不会丢已经上屏的句子。上一轮打过的词会挂在候选栏上，按输入键才切回工具栏。

## 键盘

键盘是真正的 View 树，不是贴图，所以按键能做出这些反应：

- 长按弹预览气泡，气泡能探出键盘上沿
- 长按展开九宫格扩展字符，带中文标点
- 上滑出符号、按住退格连发、空格左右滑移光标
- Caps 双击长按三态：无、一次、锁定
- `?123` / `ABC` / `!?#` 切布局只是导航，不会打断你正在打的词

候选栏跟着引擎状态走，空闲、有候选、标题三种状态自动切换。

表情和颜文字面板都有。

## 语音

内置 sherpa-onnx，说话直接上屏，不用跳去别的 App。

识别结果先挂在候选栏上，安静 0.8 秒才搬进输入框，中途发现不对还能改。

模型 239MB，设置页按需下载，不想要可以不装。

录音做了几件事：开麦前让正在放的音乐压低音量；来电或者导航播报把声音抢走时立刻中止，免得把别人的话记成你说的；收起键盘、切输入框、切到后台就马上放开麦克风，不在后台偷偷录。

## 外观

深浅色跟随系统，内置 fcitx5 默认主题。

皮肤包可以导入、复制、删除、改清单。字体自己从手机里导 `.ttf` / `.otf` / `.ttc`，不进 APK，想用哪款自己选。

还有剪贴板历史，常用的东西点一下就粘。

## 关于隐私

这个输入法只有一个地方会把你的文字送出去：翻译功能。你填哪台服务器，它就发到哪台，界面上用黄框标着。不用这个功能，就一个字都不会离开手机。

插件商店下载插件时会联网，除此之外没有别的对外连接。

录音只在内存里处理，不写文件。输入的内容不进日志。

没有广告，没有统计，没有崩溃上报。权限只要四个：震动、录音、网络、网络状态。

## 关于许可证

GPL-3.0。

原因是雾凇拼音是 GPL-3.0，词库又打包在 APK 里，传染性绕不开。

用到的开源项目：

- [librime](https://github.com/rime/librime) — 输入引擎（BSD-3-Clause）
- [rime-ice / 雾凇拼音](https://github.com/iDvel/rime-ice) — 方案与词库（GPL-3.0）
- [fcitx5-android](https://github.com/fcitx5-android/fcitx5-android) — 键盘视图层与候选栏状态机（LGPL-2.1-or-later）
- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) — 语音识别（Apache-2.0）

完整清单在 App 里的「第三方开源许可」页，每条都能点进去看上游仓库。

## 下载

装 APK 就行，需要 Android 8.0 以上，只支持 arm64。

在 [Releases](https://github.com/selenaflora927-dot/jimeng-ime/releases) 页下载最新版。

装好后到「设置 → 语言和输入法」里启用霁梦，再切换过去就能用了。
